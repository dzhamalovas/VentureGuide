# Навигатор Цифрового Предпринимателя (ИИ-Стартап)

Интерактивная платформенная система сопровождения студенческих стартапов, стартап-студий и университетского предпринимательства.

## Публикация на GitHub Pages

Проект полностью настроен для автоматической публикации в **GitHub Pages**.

### Способ 1: Автоматический деплой через GitHub Actions (Рекомендуемый)

1. Отправьте код в ваш репозиторий на GitHub (`git push origin main`).
2. В репозитории на GitHub перейдите в **Settings** (Настройки) -> **Pages**.
3. В разделе **Build and deployment** выберите **Source**: `GitHub Actions`.
4. При каждом пуше в ветку `main` или `master` автоматический workflow (`.github/workflows/deploy.yml`) соберёт проект и опубликует его на GitHub Pages.

---

### Способ 2: Ручной деплой через CLI (`gh-pages`)

Если вы хотите опубликовать проект вручную со своего компьютера:

```bash
# 1. Установите зависимости
npm install

# 2. Выполните команду деплоя
npm run deploy
```

Эта команда автоматически соберёт приложения в папку `dist` и загрузит их в ветку `gh-pages` вашего репозитория.

---

## Запуск в режиме разработки

```bash
# Запуск локального сервера разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.
